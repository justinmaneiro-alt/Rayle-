# Base de connaissances de Rayle

Sept fichiers que l'IA de Rayle charge selon la question (mots-clés dans l'en-tête de chaque fichier, repris par `trader-pro/point/connaissances.js`). Ils expliquent **comment lire** les outils ; les **chiffres** viennent toujours des fiches de lecture, jamais d'ici. Pas de module sur le money management ni sur le ratio risque/récompense. Rayle est une copilote : elle n'impose aucune méthode et ne décide jamais à la place de Justin.
