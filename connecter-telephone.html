Connecter le téléphone à Raylé

Recherche de l'adresse du PC…
Sur le téléphone
  1. Le téléphone et le PC doivent être sur le même Wi-Fi.
  2. Scanne le QR code (ou tape l'adresse) dans Chrome.
  3. Menu ⋮ → « Ajouter à l'écran d'accueil ».
Si une ancienne version de Raylé était installée : désinstalle-la d'abord, ou vide les données du site (Chrome → ⋮ → Paramètres → Paramètres des sites → Raylé).
